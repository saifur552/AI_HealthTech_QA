**Bug Title**: System accepts past date and redirects to summary page

**Severity**: High

**Environment**: Automated UI test in Katalon Studio on https://katalon-demo-cura.herokuapp.com

**Steps to Reproduce**:
1. Navigate to the appointment page.
2. Select a past date for an appointment.
3. Proceed to the next step.

**Expected Result**: The system should not allow selecting a past date for an appointment and should display an error message or prevent redirection to the summary page.

**Actual Result**: The system accepted the past date and redirected to the summary page without appropriate validation.
